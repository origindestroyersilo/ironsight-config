## 🧩 About

**Ironsight Config** is a comprehensive configuration utility for Ironsight on PC featuring sensitivity tuning, keybind editing, graphics presets, FOV adjustment, HUD layout management, and crosshair customization.

Based on popular config tools like **Ironsight Tweaker**, **Config Editor**, and **Game Settings Manager**.

---

## ✨ Features

### 🎮 Input & Sensitivity
- Sensitivity Tuner — fine-tune mouse sensitivity and aim multipliers
- Keybind Editor — remap any action to any key or mouse button
- Raw Input Toggle — bypass OS mouse acceleration
- ADS Sensitivity — separate scope/ADS multiplier sliders
- Deadzone Adjuster — tune controller stick deadzones

### 🖥️ Graphics & Display
- Graphics Presets — Low / Medium / High / Competitive presets
- FOV Adjuster — change field of view beyond in-game limits
- Resolution Switcher — custom resolutions and aspect ratios
- FPS Cap Control — set frame limiter and VSync behavior
- Shadow & Effects Toggles — disable heavy post-processing

### 🎨 HUD & Crosshair
- HUD Layout Manager — move, scale, and hide HUD elements
- Crosshair Customizer — shape, color, thickness, gap, dot
- Hitmarker Toggle — enable/disable visual hit feedback
- Minimap Settings — size, opacity, rotation lock
